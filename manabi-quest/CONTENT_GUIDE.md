# 問題づくりガイド（まなびクエスト）

国語・理科・社会・英語の問題は `public/js/data/<教科>.js` に書きます。
算数は自動で問題を作るプログラム（`public/js/data/sansu.js`）です。

| 教科 | ファイル | 教科ID |
| --- | --- | --- |
| 国語 | `public/js/data/kokugo.js` | `kokugo` |
| 理科 | `public/js/data/rika.js` | `rika` |
| 社会 | `public/js/data/shakai.js` | `shakai` |
| 英語 | `public/js/data/eigo.js` | `eigo` |

書いたら必ずチェックします。

```sh
npm run check           # 全教科
node scripts/check-content.mjs rika   # 1教科だけ
```

## ファイルの形

```js
// public/js/data/rika.js
export default {
  subject: 'rika',
  units: [
    {
      id: 'rika-kisetsu',            // 単元ID（教科ID-英小文字）
      title: '季節と生き物',          // 16文字まで
      icon: '🌸',                     // 絵文字1つ
      description: '春夏秋冬の生き物のようす', // 40文字まで
      questions: [
        {
          id: 'rika-kisetsu-001',     // 単元ID-3けたの番号（全体で重複しない）
          level: 1,                   // 1=きほん 2=ひょうじゅん 3=チャレンジ（EXステージ用）
          q: 'ツバメが日本にやってくるのは、どの季節？',
          choices: ['春', '夏', '秋', '冬'],   // 2〜4こ。正解もこの中に入れる（並びはアプリがシャッフル）
          answer: '春',                        // choices のどれかと完全に同じ文字列
          explain: 'ツバメは春に南の国からやってきて、巣をつくって子どもを育てます。',
        },
      ],
    },
  ],
};
```

### 問題のフィールド

| キー | 必須 | 内容 |
| --- | --- | --- |
| `id` | ○ | `単元ID-001` の形。あとから変えない（学習記録がこのIDにひもづく） |
| `level` | ○ | 1 / 2 / 3。ふつうのステージは 1・2、EXステージは 2・3 から出る |
| `q` | ○ | 問題文（140文字まで） |
| `big` |  | 問題カードに大きく表示する文字（30文字まで）。漢字の読みの対象の言葉、英単語、絵文字など |
| `choices` | ○ | 選択肢 2〜4こ（各40文字まで）。同じものは入れない |
| `answer` | ○ | 正解。`choices` のどれかと完全に同じ |
| `explain` | ○ | 解説（220文字まで）。答えたあと必ず表示される。まちがえた子が「なるほど」と思えるように |
| `hint` |  | ヒント（80文字まで）。ヒントボタンで表示 |
| `speak` |  | 英語の読み上げ文（半角英語だけ）。🔊ボタンと自動読み上げに使う |
| `kanjiQuiz` |  | `true` にすると選択肢の漢字チェックをしない（漢字の書き問題で、わざとまちがえた字を選択肢に入れるとき用） |

### 使える記法

| 書き方 | 表示 |
| --- | --- |
| `{地震\|じしん}` | ふりがな（ルビ） |
| `**ことば**` | 強調（マーカー） |
| `__ことば__` | 下線（「――線の言葉の意味は？」のような問題用） |
| `[[3/7]]` / `[[2 3/7]]` | 分数 / 帯分数 |
| `\n` | 改行 |

## 問題の質のルール（大事）

1. **正解はかならず1つ。** 見方によって別の答えも正しくなる問題は作らない。
2. **教科書にそろえる。** 小学校学習指導要領（2017年告示）と、4年生の教科書（東京書籍・光村図書・教育出版・啓林館・大日本図書・学校図書・日本文教出版など）の内容・言葉づかいにそろえる。自信のないことは問題にしない。
3. **地域でちがうことは出さない。** 社会の「自分の県」の内容は、どの県の子でも答えられる一般的なことにする。
4. **4年生までに習う漢字だけ。** 5年生以上の漢字は `{漢字\|よみ}` でふりがなをつけるか、ひらがなにする（チェックツールが自動で見つけます）。
5. **まちがい選択肢も本物らしく。** 同じ種類の言葉にする。ふざけた選択肢・「すべて」「どれでもない」は使わない。
6. **解説は短く、やさしく。** 「なぜその答えか」「どう覚えるか」を1〜3文で。子どもを責める言い方はしない。
7. **時間で変わる事実は出さない。** 人口・順位・最新記録など、年によって変わる数字はさける。
8. **1単元15問以上**、level 1・2・3 をそれぞれ5問以上がめやす。

## 算数（自動生成）について

算数はプログラムが毎回ちがう数で問題を作ります。問題の種類を増やすときは
`public/js/data/sansu.js` の各単元の `generate(level, rng)` を編集し、
`npm test` で答えが正しいことを確認してください。
