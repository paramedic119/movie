# まなびクエスト 4年生

小学4年生の **国語・算数・理科・社会・英語** を、ゲーム感覚でくり返し学べる Web アプリです。
スマホ・タブレット・パソコンのブラウザで動き、ホーム画面に追加するとアプリのように使えます。

- ビルド不要の静的サイト（HTML / CSS / JavaScript）。**Firebase Hosting / Cloudflare Pages のどちらにもそのまま置けます。**
- 学習記録は端末のブラウザ（localStorage）にだけ保存します。サーバーやアカウントは不要です。

## あそび方と学びのしくみ

| しくみ | 内容 |
| --- | --- |
| 正解で報酬が増える | 1問正解でコイン。**連続正解（コンボ）で1問あたりのコインが増え**、最大3倍。まちがえてもコインは減りません |
| 全問正解で追加テスト | 5問すべて正解すると **EXステージ**（追加テスト）が出現。EX1 → EX2 → EX3 と難しくなり、コインは ×2 / ×3 / ×5。EX3 をクリアするとその単元の「👑マスター」 |
| 遊びながら反復 | まちがえた問題は **まちがいノート** へ。「今日 → 1日後 → 3日後 → 7日後」と間隔をあけて復習し、4回正解で「おぼえた！」。その場でやり直す **リベンジ**、前にまちがえた問題が出やすい出題、毎回ちがう数で出る算数の自動生成も |
| きょうの5教科チャレンジ | 5教科から1問ずつ出る毎日の腕だめし。全問正解のボーナスは1日1回だけ |
| 演出 | コインが飛ぶ・紙ふぶき・なかまのおうえん・効果音（Web Audio で生成）。連続正解のたびに正解音の音程が上がり、3れんぞくで「いいかんじ！」、**5れんぞくで「フィーバー！」**（問題カードのふちが にじ色に光り、なかまがおどる。EXステージにもつづく）、8・11・14れんぞくでさらに段階アップ |
| ドキドキ・ごほうびの演出 | 全問正解まで あと1問のときは「**ラスト1問！**」（ドラムロール）。EXステージの入口はななめストライプの**カットイン**。けっか画面では ★が1つずつ「キン！」と出て、先生の**ハンコ**（たいへんよくできました／よくできました／がんばりました）、ボーナスは**たからばこ**（タップで開く。中身は決まったボーナス）、**しょうごうゲージ**がのびて「しょうごうアップ！」 |
| なかま集め | コインで動物の「なかま」やきせかえを買えます（**値段は固定。くじ引き・ガチャはなし**）。がんばると仲間になる「ひみつのなかま」も |
| 筆算モード | 小数のたし算・ひき算を、右のくらいから1けたずつ入力。まちがえると、そのけたのくり上がり・くり下がりのヒントが出ます |
| 英語の読み上げ | 端末の音声合成で英語を読み上げ（リスニング問題）。使えない端末では文字で表示 |

### 収録内容（5教科・37単元）

| 教科 | 単元 |
| --- | --- |
| 国語 | 漢字の読み／漢字の書き／漢字の組み立て（部首）／慣用句・ことわざ／つなぎ言葉と文／同じ読みの言葉・熟語 |
| 算数（自動生成） | 大きな数／わり算／小数の筆算／小数のかけ算・わり算／分数／がい数／計算のきまり／角と図形／面積 |
| 理科 | 季節と生き物／天気と気温・雨水／電流のはたらき／月と星／とじこめた空気と水／もののかさと温まり方／水のすがた／体のつくりと運動 |
| 社会 | 都道府県と地方（自動生成）／県庁所在地（自動生成）／くらしと水／ごみのしょりと利用／自然災害からくらしを守る／伝統・文化と先人／地図と県のようす |
| 英語 | あいさつと天気／曜日／数と時こく／文ぼう具／アルファベット／食べもの／学校と1日の生活 |

問題バンクは 国語108問・理科136問・社会90問・英語126問（合計460問）。算数9単元と社会の都道府県2単元は、毎回ちがう問題を自動で作ります。
各単元の問題は「きほん・ひょうじゅん・チャレンジ」の3段階。ふつうのステージは きほん〜ひょうじゅん、EXステージはひょうじゅん〜チャレンジから出ます。
4年生までに習わない漢字には、すべてふりがなをつけています（自動チェックあり）。

### 使いすぎを防ぐ・安心して使うための工夫

報酬の演出は学習の入口として強い一方、依存しやすい設計にもなりえます。そこで次の工夫を入れています。

- **1日の時間の上限**（初期値 30分）。時間になるとステージの区切りで「きょうはここまで」の画面になります。おうちの方は暗証番号で「今日だけ延長」できます
- **休けいのお知らせ**（初期値 20分ごと）
- **演出の強さ**を「おだやか／ふつう／にぎやか」から選べます。「おだやか」ではコインが飛ぶ・紙ふぶき・フィーバーのにじ色の回転・カットインなどの動きを止めます（OS の「視差効果を減らす」設定の人は最初から「おだやか」）。点滅のような強い光の演出は使っていません
- ごほうびは**正解の数とコンボで決まり**、運で変わるもの（くじ・ガチャ・ランダムな当たり）はありません。演出は遊びを止めず、タップで先に進めます
- **まちがえたときは必ず解説**を表示。子どもを責める言葉は使いません
- **おうちの方ページ**（暗証番号つき）：今日の学習時間・問題数・正答率、1週間のグラフ、教科ごとの正答率、つまずいている単元、まちがいノートの中身、各種設定
- 広告・課金・外部への学習データ送信はありません

## ローカルで動かす

Node.js 20 以上が必要です（依存パッケージなしで動きます）。

```sh
cd manabi-quest
npm start          # → http://localhost:8080 をブラウザで開く
```

`public/` フォルダをそのまま任意の静的サーバーで配信しても動きます。

## デプロイ

### A. Cloudflare Pages（おすすめ：ダッシュボードだけで設定でき、スマホからでもOK）

1. [Cloudflare ダッシュボード](https://dash.cloudflare.com/) → **Workers & Pages** → **作成** → **Pages** → **Git に接続**
2. GitHub のリポジトリ（このリポジトリ）を選ぶ
3. ビルドの設定
   - フレームワーク プリセット：**なし**
   - ビルド コマンド：**（空欄）**
   - ビルド出力ディレクトリ：**`public`**
   - ルート ディレクトリ（詳細設定）：**`manabi-quest`**
4. 「保存してデプロイ」→ `https://<プロジェクト名>.pages.dev` で公開されます

以後は、本番ブランチ（通常は `main`）にマージするたびに自動で更新されます。
まだ `main` にマージしていないときは、Pages の設定で本番ブランチをこの作業ブランチにするか、プレビュー用の URL（ブランチごとに自動で作られます）で確認できます。

コマンドで公開する場合：

```sh
cd manabi-quest
npx wrangler login
npx wrangler pages deploy public --project-name manabi-quest
```

### B. Firebase Hosting

1. [Firebase コンソール](https://console.firebase.google.com/) でプロジェクトを作る
2. パソコンで次を実行（`<プロジェクトID>` は自分のものに置きかえ）

```sh
cd manabi-quest
npx firebase-tools login
npx firebase-tools deploy --only hosting --project <プロジェクトID>
```

→ `https://<プロジェクトID>.web.app` で公開されます。設定は `firebase.json` に入っています。

### C. GitHub Actions から手動でデプロイ

`.github/workflows/manabi-quest-deploy.yml` を用意しています。リポジトリの **Settings → Secrets and variables → Actions** に次のシークレットを登録し、**Actions タブ →「まなびクエスト デプロイ」→ Run workflow** でデプロイ先を選びます。

| デプロイ先 | 必要なシークレット |
| --- | --- |
| Cloudflare Pages | `CLOUDFLARE_API_TOKEN`（Pages の編集権限）、`CLOUDFLARE_ACCOUNT_ID` |
| Firebase Hosting | `FIREBASE_SERVICE_ACCOUNT`（サービスアカウントの JSON）、`FIREBASE_PROJECT_ID` |

※ GitHub の仕様で、「Run workflow」ボタンはこのワークフローが既定のブランチ（通常は `main`）に入ってから表示されます。

## テスト

```sh
npm run check      # 問題データのチェック（形・答え・4年生の漢字・ふりがな）
npm test           # ユニットテスト（算数の自動生成問題を大量に作って検算、復習の間隔、コイン計算など）
npm install && npx playwright-core install chromium
npm run e2e        # ブラウザで全教科を通しプレイ（全問正解→EX、復習、時間上限、保護者ページ、スマホ幅）
```

`push` / `pull_request` のたびに GitHub Actions（`.github/workflows/manabi-quest-test.yml`）で同じテストが走ります。

## 問題の追加・修正

国語・理科・社会・英語の問題は `public/js/data/<教科>.js` に書かれています。書き方と品質のルールは **[CONTENT_GUIDE.md](CONTENT_GUIDE.md)** を見てください。修正したら `npm run check` でチェックできます。
算数と都道府県の問題はプログラム（`public/js/data/sansu.js`・`todofuken.js`）で自動生成しています。

```
manabi-quest/
├─ public/                 ← これをそのまま公開する

├─ tests/                  ユニットテスト
└─ e2e/                    ブラウザでの通しテスト
```

## メモ

- 記録はブラウザごと・端末ごとに保存されます。ブラウザのサイトデータを消すと記録も消えます。
- おうちの方ページの暗証番号は、端末の中だけで使う簡単なカギです（強いセキュリティではありません）。
- 文字は Google Fonts（M PLUS Rounded 1c・Klee One）を使います。読みこめない環境では端末の文字で表示されます。
