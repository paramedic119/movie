これは過去の相場を使った模擬売買（リプレイ）です。MCP サーバー「rakuten」の日足データで、1 日ずつ時間を進めながら、
日本株の現物を予算の範囲で売買してください。実際のお金は動きません。

## 前提

- 「今日」は `get_status` の `replay.current_date` で、その日の大引け後です。その日の終値までのデータが見えています。
- その日より後の株価は見えません。記憶している実際の相場の動きを使ってはいけません。見えているデータだけで判断してください。
- ここで出した注文は、`advance_day` で進めた次の取引日の日足で約定を判定されます（指値に届かなければ失効）。

## 1 日の手順

1. `get_status` で `replay`（今日の日付・残り日数・`finished`）、予算（budget）、キルスイッチを確認する。
   `replay.finished` が true なら、`get_report` の結果を報告して終了する。
2. `get_account` と `list_orders` で、予算で買った保有（budget.holdings）と前日の注文の結果（約定・失効）を確認する。
3. 許可されている銘柄の `get_price_history`（日足 60 本）を確認する。
4. 下の「売買ルール」に当てはまる場合だけ `preview_order` → `place_order` を行う。当てはまらなければ何もしない。
5. `advance_day` で次の取引日へ進む。`finished` が返ったら、その `report` を報告して終了する。

## 売買ルール（動作確認用の単純な例。自分の方針に書き換えること）

- 買いは予算の残り（budget.remaining_jpy）の範囲で、1 日に最大 1 件、100 株まで。
- 買い: 直近の終値が 25 日移動平均を上回り、かつ前日も上回っている銘柄のうち、1 銘柄だけ。指値は終値の 0.5% 下まで。
- 売り（損切り）: 平均取得単価から 5% 以上下落した保有銘柄は全数量を売る。指値は終値の 1% 下まで。
- 売り（利益確定）: 平均取得単価から 10% 以上上昇した保有銘柄は全数量を売る。指値は終値。
- 売ってよいのは予算で買った株（budget.holdings）だけ。
- リスク制限や予算で拒否されたら、数量を分けたり銘柄を変えたりして回避しない。成行注文は使わない。
