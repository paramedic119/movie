# LUCAS3 バッテリ更新計画（R9修正）

犬山市 自動式心マッサージ器（LUCAS3）の予備バッテリ購入計画。
元資料「保守点検及び本体、バッテリ更新計画（2026.5修正）」の R9「予備3個購入」を見直したもの。
機器更新・保守点検のスケジュールは元資料から変更していない。

## 成果物

`犬山市_LUCAS3バッテリ更新計画_R9修正.xlsx`（5シート）

| シート | 内容 |
| --- | --- |
| 比較まとめ | 元計画／3年維持版／4年維持版の年度別購入数・差引・事業費試算 |
| 3年維持版 | 元資料と同じ年表形式。車両ごとのイベント・搭載バッテリ年式・購入数・判定 |
| 4年維持版 | 同上 |
| 作業手順 | 年度ごとの入替・購入作業 |
| 前提条件 | 耐用期間、判定ルール、元資料の備考、要確認事項 |

## 結論

| 区分 | R9〜R19 合計 | 内訳 |
| --- | --- | --- |
| 元計画（2026.5修正） | 12個 | R9・R12・R15・R18 に各3個 |
| 3年維持版（車両間入替あり） | 6個 | R10・R11・R15・R17・R18・R19 に各1個 |
| 4年維持版（車両間入替あり） | 3個 | R11 に1個、R18 に2個 |
| 参考：3年維持版（入替なし） | 12個 | |
| 参考：4年維持版（入替なし） | 5個 | |

R9 はいずれの案でも購入0個。救急犬山2の機器更新で新品バッテリ2個が付属するため。

## 再生成

```bash
pip install openpyxl
python3 generate_plan.py
```

購入数・判定はすべて Excel 数式。判定基準（各年表シートの B3）を書き換えると全年度の判定が再計算される。
