# rotoanime

実写動画をセル画調に変換するローカル CLI パイプライン。GPU・外部 API・モデル
ダウンロードは不要で、CPU だけで完走する。

```bash
pip install -r rotoanime/requirements.txt        # ffmpeg も別途必要
python -m rotoanime probe INPUT.mov              # 素材の検査だけ
python -m rotoanime run INPUT.mov -o out.mp4 --duration 3
```

いきなり全編を回さないこと。まず `--duration 3` で先頭3秒を見てから進める。

## 何をしているか

```
ingest → 被写体マスク → [線画レイヤ] → [色レイヤ] → 時間安定化 → 合成 → encode
```

* **ingest** (`video.py`) — HEVC / VFR / 回転メタデータ / HDR を正規化して PNG 展開。
  VFR のまま展開すると最後に音がズレる。HDR は `zscale` か `libplacebo` の
  どちらが実際のビルドにあるかを見てから選ぶ（両方無いビルドがある）。
* **被写体マスク** (`pipeline.refine_mask`) — mediapipe の selfie_segmentation。
  重みは wheel に同梱されているのでダウンロード不要。逆光素材では手足が欠ける
  ため、近傍の暗部で補完し、被写体本体と繋がる成分だけ残す。
* **線** — CLAHE で局所コントラストを起こしてから、平滑化後の輝度に Canny。
  被写体の輪郭はマスク境界から引くので、閉じていて太さが均一になる。
* **色** — バイラテラルで面を作り、輝度だけを階調化して色相は保つ。背景は
  階調数を落として白へ持ち上げる。
* **時間安定化** (`pipeline.Stabilizer`) — 元の実写フレームからフローを取り、
  forward-backward consistency でオクルージョンを除いて出力を warp 合成。

## 設計上の決定と、その根拠

参照映像（Instagram `knot_animation` の画面収録）を実測して決めたもの。

**フローは元の実写フレームから取る。** 平坦化後の絵に `DISOpticalFlow` を
かけると、フロー補正後の残差がかけない場合より **19.5% 悪化**した。平坦な
塗り面には追跡できる特徴が無いため。順序を入れ替えてはいけない。

**スタイル適用は鮮明な元フレームに対して行う。** 先に安定化をかけると、線の
元になるディテールが消えて輪郭だけの絵になる。

**コマ打ちはしない。** 参照映像は 60fps 中 342/358 フレームが毎フレーム更新で、
差分は lag に比例して増える（＝圧縮ノイズではなく実際の動き）。実効 58fps。
「8〜12コマ/秒で絵を保持する」は、少なくともこの参照には当てはまらない。

**線は必ず平滑化後の輝度から取る。** 元画像に直接かけると布のシワや砂利の
テクスチャを拾う。階調はビン中央値を使う（黒潰れを防ぐ）。

**輝度係数は BGR 順** (`0.114, 0.587, 0.299`)。OpenCV 前提。RGB 環境
（ブラウザ等）へ移植するときは順序を反転しないと輝度が壊れる。

## 既知の限界

* **ちらつきの主因は時間安定化では取れない。** 量子化の帯がフレーム間で飛ぶのが
  主因で、warp 合成では直らない。実測（実素材45フレーム）:

  | | フレーム間差分 |
  |---|---|
  | 入力そのもの | 0.0602 |
  | スタイル適用のみ | 0.0279 |
  | ＋時間安定化 | 0.0255 |

  安定化の寄与は約 10%。安定性のほとんどは平坦化そのものから来ている。
  合成素材のように元がきれいだと、スタイル適用は逆にちらつきを**増やす**
  (0.016 → 0.033)。

* **セグメンテーションは人物向け。** 人以外の被写体では背景の省略が効かない。
  細い手足や、背景と輝度が近い部分は落ちる。

* **参照スタイルには届かない。** 参照は「砂利を3本の線に省略する」といった
  意味的な判断をしている。画素単位のフィルタはその判断ができない。届かせるには
  拡散モデルによるキーフレーム生成＋EbSynth 系の伝播が要る（GPU 必須）。

## 撮影側の条件

ロトスコープ系は素材の撮り方で仕上がりが決まる。

* 光は柔らかく。影が動くと線がチラつく
* 逆光を避ける。被写体が潰れて内部の線が出ない
* 被写体はテクスチャのある素材が有利。てかる素材・のっぺりした単色は追跡が弱い
* 動きの速いカットは 60fps で撮る
* 背景はシンプルに。水面のきらめきや細かい葉は線が暴れる最大の要因

## 出力

H.264 / yuv420p / AAC / `+faststart`。iPhone の写真アプリと Instagram で
そのまま再生できる。元の fps・アスペクト・音声を維持する。

## ライセンス

mediapipe は Apache-2.0。同梱の selfie_segmentation モデルも同ライセンスで
配布されている。商用利用に制限のあるモデル（AnimeGAN 系など）は現時点で
使っていない。
